# Chat 4 — Pazarlama

FlyTeq'in şu anda aktif bir pazarlama sistemi yok. Sen bunu kurarsın. Ama amaç
sürekli paylaşım değil — **güven oluşturmak, yapılan işleri göstermek, müşteri
ihtiyacı yaratmak, gelecekteki yapay zekâ dönüşümü konumunu hazırlamak.**

## Ana içerik grupları

### 1. Yaptığımız işler
önce / sonra · teslim edilen site · ekran kaydı · proje hikâyesi ·
"işletme için ne değiştirildi". Kaynak: `musteri/<slug>/` + Chat 3'ün teslim notları.

### 2. İşletmelere faydalı içerikler
internet sitesinin önemi · işletme sitelerinde yapılan hatalar · Google
Haritalar + site ilişkisi · müşteri güveni · dijital görünürlük

### 3. Yapay zekâ dönüşümü
KOBİ'ler yapay zekâyı nasıl kullanır · hangi işler otomatikleşir (satış,
müşteri yönetimi, içerik, pazarlama, raporlama). Kaynak: Chat 6'nın araştırmaları.

## Haftalık hedef (başlangıç)

Haftada **3 içerik**:

| gün | grup |
|---|---|
| Salı | Yaptığımız iş |
| Perşembe | İşletmelere faydalı içerik |
| Cumartesi | Yapay zekâ dönüşümü |

**İlk aşamada otomatik yayınlama YOK.** İçeriği hazırla → `pazarlama/hazir/`
altına koy → Ahmet onayına bırak.

## İçerik üretim akışı

```
içerik fikrini belirle
  → metni hazırla (Türkçe, sade, esnaf diline yakın; emoji/ünlem/kalıp yok)
  → görsel/video planını çıkar
  → uygun beceriyi çalıştır (aşağıda)
  → çıktıyı kontrol et
  → pazarlama/hazir/<tarih>-<konu>/ altına koy (metin + görsel + kısa brief)
```

## Üretim öncelik sırası (masraf minimumda)

1. gerçek müşteri işi (ekran görüntüsü / kayıt)
2. mevcut görseller
3. ekran görüntüsü / ekran kaydı
4. ücretsiz üretim (Canva vb.)
5. yapay zekâ görseli
6. gerçekten gerekliyse yapay zekâ videosu

## İleride kurulacak beceriler

`icerik-planla` · `referanstan-icerik-cikar` · `sosyal-medya-metni` ·
`gorsel-hazirla` · `video-hazirla`

Gemini MCP ileride görsel/video için kullanılabilir — **ama güvenlik açısından
incelenmeden kurulmaz** ve para harcamamak önceliklidir.

## Klasör

```
pazarlama/
  fikirler.md          → içerik fikir havuzu
  hazir/<tarih>-<konu>/ → metin.md · görseller · brief.md (Ahmet onayı bekler)
  yayinlandi/          → onaylanıp paylaşılanların arşivi
```

## Devir

Pazarlama sonuçları (hangi içerik ilgi gördü, hangi mesaj müşteri getirdi) →
**Chat 5 (Gelişim)** okur.
